# The female body map's generator

`src/bodyMapData.js`'s `BODYMAP_FEMALE` is GENERATED by `gen.mjs` (which needs `kit.mjs`), not
hand-authored and not traced. It lives in the repo rather than in a scratchpad for the reason the
sim battery was once lost: a container recycle wipes anything outside git, and a data file whose
generator is gone can only ever be hand-edited afterwards — which is exactly how the geometry it
guarantees would drift.

    cd build/bodymap && node gen.mjs      # writes female_new.json next to it

Then splice `{front, back}` in as `export const BODYMAP_FEMALE` in `src/bodyMapData.js` and run
BOTH guards before believing anything:

    node build/sim_bodymapfemale.mjs      # keys, bounds, the size pins, region-subpath⊂_body
    node build/pw_bodymapfemale.mjs       # rasterised: every region's ink inside its silhouette

## What the kit does, and the one property everything rests on

`spline()` turns a closed Catmull-Rom point list into cubic Béziers; `band()` cuts a muscle out of
a limb defined by a centre line and a width function, so every limb muscle inherits its limb's
taper and every end gets a real rounded cap — there is nothing for a needle to form on, which is
what the previous traced map kept producing.

`assemble()` builds `_body` by CONCATENATING the very subpath strings the regions are made of, plus
fillers (neck, clavicle, linea alba, armpit, elbow, wrist, pelvis, kneecap, ankle; back: scapula,
spine, sacrum, popliteal, soleus). So a region can never sit outside the silhouette — registration
holds by construction rather than by care, and `sim_bodymapfemale` asserts it literally, as a
substring test. Note this is a FEMALE-ONLY property; the male map does not have it.

The back view is the front's frame under ONE uniform similarity, fitted on the two landmarks the
two figures actually share — deltoid top and ground line. Never fit on outer extent: this figure
has no head, so matching bounding boxes puts her shoulders where the male's neck is and stretches
the body to fill the gap.
